# Classic Calculator (React)

A retro style calculator built with ReactJS.

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build & Deploy

```bash
npm run build
```
Host the "build" folder via Netlify, Vercel, or GitHub Pages.

## Features
- Classic UI
- Basic arithmetic operations
